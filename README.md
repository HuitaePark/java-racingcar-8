# 🗂 미션 - 자동차 경주 기능 목록

## 📚 기능 목록

### 기능 요구 사항
- [ ] 입력받은 자동차의 이름을 쉼표를 기준으로 구분한다.
- [x] 구분된 정보를 바탕으로 자동차 객체를 생성한다.
  - [x] ⚠️ 자동차의 이름이 5자 이하인지 검증한다.
  - [ ] ⚠️ 이름이 중복되었는지 검증한다.
- [ ] 입력받은 경주 시도횟수 만큼 게임을 진행한다.
  - [ ] ⚠️ 횟수가 너무 많이 않은지 검증한다.
- [x] 무작위 값을 구하고 4 이상일경우 한칸 진행한다.
- [ ] 게임이 끝나면 제일 많이 진행한 우승자를 구한다.
  - [ ] 우승자가 여러명일경우 쉼표를 이용하여 구분한다.

### 입출력 요구 사항
- [ ] 경주할 자동차 이름을 입력을 받는다.
  - [ ] 이름이 쉼표로 구분되었는지 검사한다.
- [ ] 경주 시도 횟수를 입력받는다.
- [ ] 차수별 실행 결과를 출력한다.
- [ ] 우승자(들)을 출력한다.
 
### 프로그래밍 요구 사항

- [ ] JDK 21 버전을 사용한다.
- [ ] Application main() 에서 프로그래밍을 시작한다.
- [ ] build.gradle을 변경하지 않는다.
- [ ] System.exit()를 호출하지 않는다.
- [ ] 사용자가 입력하는 값은 camp.nextstep.edu.missionutils.Console의 readLine()을 활용한다.
- [ ] Random 값 추출은 camp.nextstep.edu.missionutils.Randoms의 pickNumberInRange()를 활용한다.
- [ ] Java Style Guide를 지키며 프로그래밍 한다.
- [ ] 명시하지 않은 파일이나 패키지를 바꾸거나 이동하지 않는다.
- [ ] indent(인덴트, 들여쓰기) depth를 3이 넘지 않도록 구현한다.
- [ ] 3항 연산자를 쓰지 않는다.
- [ ] 메소드가 한가지 일만 하게 만든다.
- [ ] 테스트 코드를 작성한다.
